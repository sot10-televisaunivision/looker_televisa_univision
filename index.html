Dashboard headers

Full-width banner for the top of a dashboard. The HTML header takes any section name; the image headers paste as markdown into a Text tile.

Full-width Text tile (24 wide × 3 tall) at the top of the dashboard: Edit dashboard → tile menu → Edit → replace the body → Save. Keep it on one block with no blank lines.

Custom visualization

Custom table viz: merged dimension cells, collapsible groups, per-field header images, in-cell bars, conditional formatting, subtotals, transpose and pivot headers.

How to use

Already registered in Looker (Admin → Platform → Visualizations, ID collapsible_report_table). In an Explore or tile, pick "Collapsible Report Table" from the visualization menu; styling options are in the viz's Edit panel.
